# poverty_prediction_challenge
This repository contains the implementation of the Poverty Prediction Challenge in the scope of the ML course in AUTH CSD AI Master Program.
Check the pdf report for a detailed analysis of the procedure. 

Here is a short description of the included notebooks:
- data_preprocessing: data preparation, feature engineering.
- ml_algorithms: training and comparative analysis of ML algorithms.
- keras_tuner: tuning process of a Deep Learning Model with the keras tuner.
- optuna_tuner: tuning process of an XGBoost Regressor with the optuna package.
- extract_results: using the saved models to produce the submission files.
